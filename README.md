# Netflix Clone 🎬
 
A frontend clone of the Netflix landing page built as a UI practice project.
 
## Features
- Netflix-style hero section
- Movie/show card grid layout
- Responsive design
- Hover effects and animations
  
## Tech Stack
- HTML
- CSS
  
## Background
Built as a UI practice project to strengthen HTML/CSS skills by recreating a well-known, complex interface. Focus on layout, positioning, and responsive design.
